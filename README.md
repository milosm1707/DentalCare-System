# DentalCare-System
DentalCare System je mikroservisna aplikacija koja omogućava stomatolozima da upravljaju svojim pacijentima, zakazivanjem termina, tretmanima i medicinskom dokumentacijom, dok pacijentima omogućava pregled svojih termina, istorije tretmana i generisanje potrebne dokumentacije.

Tip aplikacije: Veb aplikacija
Tehnologije:

Backend: Rust
Frontend: Angular
Kontejnerizacija: Docker
Baze podataka: PostgreSQL (relacione baze)

4 servisa sa sopstvenim bazama, autentifikacija/autorizacija, CRUD operacije, međuservisna komunikacija
Generisanje PDF-a, generisanje QR koda, analitike u formi grafikona
